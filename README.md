# 🌐 AWS Networking Zero to Hero

A comprehensive learning repository documenting my journey to mastering **AWS Networking** from the fundamentals to advanced enterprise networking concepts.

This repository serves as my personal knowledge base, hands-on lab collection, notes, and practical implementations while learning how networking works both in general and within the AWS ecosystem. The goal is not only to understand individual AWS networking services but also to learn how they interact in real-world cloud architectures.

The content in this repository is organised according to a structured learning path, progressing from networking fundamentals to designing and troubleshooting production-ready AWS environments.

## 🎯 Objectives

* Build a strong foundation in computer networking.
* Master core AWS networking services and concepts.
* Understand network design from a cloud architect's perspective.
* Gain hands-on experience through practical labs and exercises.
* Learn production-level networking patterns and best practices.
* Develop troubleshooting skills for real-world networking issues.
* Prepare for AWS and DevOps interviews with practical knowledge.
* Document learning in a structured and reusable format.

## 📚 Topics Covered

The learning journey includes:

* Networking Fundamentals
* Amazon VPC
* Subnets & CIDR
* Route Tables
* Internet Gateway
* NAT Gateway
* Security Groups
* Network ACLs (NACL)
* Amazon Route 53
* Elastic Load Balancing (ALB, NLB, GWLB)
* Auto Scaling
* VPC Peering
* AWS Transit Gateway
* VPN & AWS Direct Connect
* VPC Endpoints & AWS PrivateLink
* Hybrid Networking
* Monitoring & Troubleshooting
* AWS WAF & AWS Shield
* Amazon EKS Networking
* Real-world AWS Networking Architectures

## 💡 Learning Approach

Each topic is studied with a practical mindset by following a simple progression:

1. Learn the core networking concept.
2. Understand how AWS implements it.
3. Perform hands-on practice.
4. Document observations and key learnings.
5. Explore real-world use cases.
6. Solve troubleshooting scenarios.
7. Review interview-focused questions.

This approach helps bridge the gap between theory and practical implementation.
